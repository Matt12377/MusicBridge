# 樱花玻璃 HTML 预览

独立视觉方案，不是正式应用，不访问 Roon、网易云、库存、钥匙串或磁带资料。

打开 `index.html` 即可查看。需要本地 HTTP 预览时，在本目录运行：

```bash
python3 -m http.server 4178 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:4178/ 。无需安装依赖或运行 Electron 构建。

## 设计与范围

- 樱粉、奶油白、淡蓝与淡紫贯穿背景；侧栏、歌曲面板和底部播放器使用不同厚度的乳白玻璃。
- 保留 Music Bridge 现有导航分组，采用清晰的系统中文字体。用户参考中的像素字体、Logo 与曲目不是复刻目标。
- 可体验搜索、排序、喜欢、模拟播放/暂停/上一首/下一首、进度调节、队列、音质与连接说明。
- 各导航入口用于展示同一套材质；收藏和录音是明确标注的布局占位，不等于正式功能已迁移。
- 所有曲目均为合成演示数据，图片为示意照片；播放仅更新界面计时，不输出声音。刷新清空演示状态。
- 正式应用源码没有修改。真实播放恢复、视觉验收、上线与发布仍是独立事项。
