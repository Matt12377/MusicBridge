# MBRS-003 离线试用

双击同目录的“启动离线试用.command”，或在终端执行项目内 TRY_OFFLINE.command。

启动后，从菜单栏托盘选择 **Open Music Bridge** 显示窗口；选择 **Quit Music Bridge** 退出。关闭窗口通常只隐藏。若终端报告路径不可用，请使用交接中的固定工作区，不要重新安装或重建它。

该入口使用已经构建和验证的N42版本，生产输入与当前T逐字节相同；本次没有重新启动App或追加桌面验收。每次试用创建独立外置目录，不改已有测试资料，也不自动清理。

此版本供界面和离线合成流程试用，使用合成服务和模拟钥匙串。当前阶段已获Owner接受；真实账号、真实曲库及实际播放在完整产品完成后验收。
