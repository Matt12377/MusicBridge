# ADR-027：Main持久outbox与Core数据集执行边界

状态：TASK067采纳；本地自动Gate通过，Owner与完整V3验收单独记录。

## 决策

Main独立单写者私有账本，不包含在collection备份中；完整不可变请求和业务commandId先持久再发送。状态更新与回执保存事务化；重启把在途状态投影为待确认，不自动发送。原DTO通过既有严格领域validator及明确命令白名单，不允许任意IPC/内部命令。标准化照片受单项及总字节上限，用户内容不进入日志或报告。

PREP一次确认撤销多个文件授权使用专用批次入口，1～3项、固定撤权命令、同工作库、不同命令ID及目标ID；先在一个事务中保存整组原请求，再开始任何业务发送。Renderer刷新不能丢失尾项。每项仍有独立业务幂等回执，部分失败不回滚已发生业务，尾项保留待确认；Main冷启不自动重放。批次不是通用命令入口，也不把撤权扩展为删除文件。

私有outbox单项请求限制2 MiB，总量64 MiB和1000条。仅在容量不足时事务清理已确认成功或已明确放弃跟踪的outbox记录；未确认项、领域账本、文件和音频不清理。此容量管理不改变F-01保留政策。JSON对象中可选undefined按落盘省略语义归一，未知字段仍先由严格领域校验拒绝。

Renderer编辑上下文持有当时datasetId，不能由Main发送时换成当前ID。Core固定本进程打开的实际repository身份，有限outbox.execute最后核对scope后按白名单路由，不能嵌套或访问credential/native路径命令。默认库身份在独立维护存储中持久，原文件替换/重建不可重用旧命令身份；恢复用新激活身份，跨切库的未确认项只读保留。

原生选择只恢复原回执或等待用户明确重新选择；录音激活先查询原终态，未终态才按原确认与当前scope继续，禁止已经active后再重启。播放和未来硬件录音不进入通用outbox。

界面沿用既有导航与设计token，全局未确认操作入口不新增侧栏。展示来源工作库、领域/命令、状态、冲突与放弃跟踪语义；只有明确点击才重试，同项singleflight。成功结果经Renderer确认后从待处理视图隐藏；不是撤销业务或删除历史事实。
