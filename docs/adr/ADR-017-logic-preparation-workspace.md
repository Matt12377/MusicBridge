# ADR-017：Logic 工作副本、发布回执与恢复

状态：TASK-057 采用。此工作区不是 Frozen PREP、执行资产、录音许可或归档。

## 背景

PRD §15 要求把精确数字版本交给 Logic，但 MusicBridge 不负责控制 DAW。TASK-056 的 Frozen Master/Layout 已提供内容身份与 Planned Timeline；Preparation 不能从当前可变草稿重建旧版本，也不能改写原始音乐库。

## 决策

1. 提案只引用冻结布局和已授权目标目录。Core 从布局逐曲的 sourceBindingId 取得原始绑定，对照冻结母版的 Hash、大小和技术信息；当前草稿改名或改序不会改变导出内容。Renderer 不提交源路径、音频内容或自造谱系。
2. Main 使用原生目录选择器，Core 持久化目标 capability。绝对路径仅存在于 Main/Core 与私有数据库中；Preload 只暴露专用业务方法。目标不能位于任何已登记 Source Root 内，撤销过的源根也不变成允许写入的目标。
3. 每个 commandId 对应一个排他创建的 MusicBridge-Preparation 子目录。目录有随机归属标记及 dev/ino 身份；子目录逐级保存身份。拒绝已存在目录、符号链接、目录置换和越界相对路径。所有输出路径由程序生成，不从曲名拼接文件名。
4. 原件以只读句柄打开，逐块检查取消，核对源身份和完整 Hash。目标文件排他创建，独立存储字节，不用指向原件的硬链接；同步后重读输出 Hash，最后再次检查源身份。不会修改原件的内容、标签、权限或修改时间，不承诺操作系统读取访问时间不变。
5. 输出包含 Sources、Tracklist.tsv、SourceLineage.json、README.txt、Manifest.json，以及 Cassette A/B 或 DAT Program 的 Bounce Targets。清单保存冻结版本身份、精确 Planned Timeline 与逐份输出摘要。SourceLineage 保存绑定编号、Hash、大小及技术证据，不保存原库路径。TSV 文本消除分隔符及公式前缀风险。
6. Schema 9 先持久化任务与幂等账本，再记录独占目录、进度、完整输出列表和清单字节 Hash。全部文件核验后才写最终 Manifest；再次核验发布对象后，在一个数据库事务内写工作区快照和完成状态。工作区快照与账本禁止 SQL UPDATE/DELETE。
7. 复制、发布、数据库回执是不同阶段。发布后数据库失败保持 interrupted；冷启动只读取归属与 Hash 完整的已发布输出并补回执，不重读原源、不重放复制。复制中退出、文件被编辑、归属改变、清单不完整时保持 interrupted。已取消或失败的任务不自动恢复成完成。
8. 源撤权通知活动复制立即 abort。目标撤权同时取消复制与该目标的恢复核验，最终提交前再次检查授权。取消及迟到结果不能完成任务；磁盘满独立报告。失败回写遇到短暂数据库错误时保留待回写状态，不产生未处理 Promise 拒绝或自动再复制。
9. 不自动删除任何工作区。失败、中断、取消可能留下不完整目录；UI 明示目录存在不代表完成，用户可自行检查。此策略避免自动清理波及已经交付、后来编辑或非本操作的内容。
10. “在 Finder 中打开”只接受已完成工作区 ID，经 Main-only 上下文取得授权且归属未变的目录。该操作不重新认定编辑后的副本为源；导入 PREP 必须独立校验。不会启动、脚本控制或写入 Logic 项目。

## 有界性与限制

每个草稿最多 100 个工作区和 1000 个任务，最多登记 100 个目标目录，同时运行最多 2 个复制任务。工作区历史与任务状态可跨启动读取；面板支持原 commandId 重试，通用跨 Renderer/应用重启的未确认操作 outbox 仍是后续工作。

目标的 realpath、目录身份、文件身份与归属会在文件操作前后复核；应用不宣称这些检查为同用户恶意并发文件系统操作提供原子 OS 沙箱。应用私有目录权限为 0700，新文件为 0600；不把权限、根目录或符号链接异常当成允许继续的理由。

工作副本可供用户编辑。历史仅记录导出时的验证结果，不代表后来文件持续保持该 Hash，也不是长期保存保证。缺少真实 Source Roots/目标目录授权时只用隔离合成数据测试。真实 Logic 操作、Render 导回、Marker 确认、Conformance、Frozen PREP、设备输出、录音与 Owner 验收均未由本 ADR 通过。
