# ADR-051：原 Node boot 后附加可选 Rust 读者

状态：已采用，2026-10-03。关联 RUST-014。

013只读签名包与原控件通过，但普通用户没有开关/快照刷新入口。已有强启动组合会在初始 Rust失败时关闭Node，无法直接catch后复用同作者。26型号成本没有证明稳定生产加速。

保留唯一原Node boot/写入及默认OFF，在已boot来源上附加借用readonly-router；Main保存boolean，可信私有port只传意图/刷新/安全状态，能力仍在Core固定Resources/pin/profile。用户启用失败继续标准查询，已发请求不透明重投。OFF先撤销发布权，再等真实native收口；未知失败本Core封禁再创建，完整Core冷启才开启新代际。

正常用户通过原设置/库存控件操作，不让路径/pin或诊断controller进入公开API。复用既有代际/写后失效/空claim合同，快照由显式用户刷新和首次ON建立。默认不增加源探测或Rust启动成本。异常状态与保存意图分别展示，代理负责全部中间验证。

代价：借用manager/privateport增加生命周期与迟到控制，需要真实关闭证据、原Node唯一性和并发行为测试；本期仍固定v2/2000预算，超限回退有界，不据此宣称完整迁移。正常签包与合成/普通CUA/真实服务/Owner使用保持独立证据。
