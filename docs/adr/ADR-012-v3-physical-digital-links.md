# ADR-012：实体发行版与 Roon 数字目录的独立身份

## 决策

原版 CD/磁带保持已有发行版 UUID；数字对象另用本地 UUID。双方通过用户明确选择的 Exact、Probable、Related 关系连接。相同标题、艺术家、时长或技术规格均不自动建立 Exact。CD Rip 是用户单独确认的来源声明，只有原版 CD 的 Exact 关系允许记录。

数字对象只持久化标题、艺术家、年份和版本元数据。Roon 的运行期公共引用、itemKey 和 session 不存入收藏数据库或账本，命令请求只存不可逆指纹及本地结果身份。协调器在内存维护最多 4096 个定位引用；重启保留实体关系，定位状态为 needs-resolution。

断连立即使公共浏览作用域失效；在断连前发出、断连后返回的浏览结果不能写入新作用域。重新定位必须由用户确认当前候选，且元数据与原数字快照一致；不同快照需新建数字对象，不覆盖旧关系。此一致性检查只保护目录身份，不是 Source Lock、字节 Hash 或音频来源证明。

## 存储与事务

Schema 4 增加 digital_albums、physical_digital_links、physical_digital_absence 和不可变 physical_links_ledger。迁移与现有库存/照片/音乐迁移在同一写事务中进行；失败保留旧版本。关系变更按 commandId + 完整请求指纹幂等，revision 防止陈旧编辑。一个发行版最多关联 20 个数字对象，一个数字对象最多关联 100 个实物发行版。

Physical Only / Digital Only 必须由用户明确声明。未检查显示待核实；删除关系不自动生成缺少声明。新关系在同一事务撤销双方相冲突的缺少声明。矩阵仅按本地身份和确认的关系聚合，不按标题去重；Exact 数量与可能/相关关系分别显示。

## UI 与异常恢复

V3 实体详情提供 Roon 候选选择与已保存数字对象选择，矩阵位于实体音乐库内部，不修改 V2 Library/Search/Album。数字详情可返回实物，查看当前 Roon 曲目并通过现有播放接口试听；试听不进入正式录音。

取消不写入。明确的请求拒绝允许刷新后重新确认；回执未知保持原 commandId 重试。弹窗退出时关闭原生 dialog，恢复焦点；运行中断连使试听立即不可用，已存关系仍可查看。跨应用重启的未确认命令 outbox 仍是后续恢复任务，不能以数据库幂等替代。

## 验证与后续

合成底层 Roon 服务仅在 Core test + UI E2E 双开关下创建，走正式公共目录、协调器、IPC 和 SQLite。合成服务不提供试听或队列成功证据。自动测试不能代表真实 Roon、Owner 美观验收或真实录音。

历史/正式自录沿 Recording/Master/曲目数字源关联，不计商业原版收藏；后续 Master Source Picker 与归档任务继续实现该谱系。F-01 与 Gate A～E 保留原边界。
