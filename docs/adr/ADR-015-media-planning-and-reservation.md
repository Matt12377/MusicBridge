# ADR-015：分面规划与库存预留

状态：TASK-055 实现决策。不是正式录音方案冻结，F-01 与真实输出 Gate 保留。

## 分面与执行分开

MediaLayout 使用显式毫秒时基，恒为 `executionReady=false`。Cassette 分为 A/B，DAT 仅有 Program。辅助平衡仅移动连续曲序的分界，不重排全局曲目。逐曲 Keep With Next、指定面、首末曲和间隔覆盖参与约束；不满足时显示冲突，不给出可预留候选。

每面从独立 Lead-in 开始，只计算同面实际相邻曲目的 Gap，最后一首没有额外 Gap，再加 Tail。空面为零。未知曲长保持未知，不填零；任何已知面超出单面容量都判为不足，不能凭总时长通过。当前按 SKU 标称总时长的一半估算 Cassette 单面容量，尚不是实测安全容量。冻结/正式预检必须重新确认介质、输出和容量。

Roon 草稿时长支持初步准备；实际源绑定且人工确认后优先取源技术时长。已绑定但不可用或未确认的曲目不回退为可录的估算。规划保存草稿修订和输入摘要；读取时重新检查当前源资格与预留副本，发现变化标记 `requiresReview`。保存并未建立 MasterVersion/LayoutVersion，后续冻结需要独立不可变对象和完整源复核。

## 库存事务

Schema 7 在同一 SQLite 中加入 media_plans、media_reservations 和不可变 media_ledger。迁移、规划、预留与取消都使用单一事务；写入失败回滚 Pool、Physical Copy、实体序号、库存账本和规划账本。

推荐候选只包括现有 Pool 与可用的 blank/erased Copy，并保留型号、版次、SKU、未拆/已拆、照片引用、数量和排除原因。Collector、封存保护和型号整体最低未拆保留量不因 SKU 不同而绕过。查询不会实例化或预留；默认优先已拆，候选分页显示，页内按适配状态排序。

明确预留时再核对最新输入、规划修订与库存。优先复用已有实体；否则从 Pool 实例化后预留，总拥有数不变。取消恢复原 blank/erased 状态，永久 ID 保留，不返池。库存页的通用取消不能绕开录音规划归属。标记不可用仍允许作为用户事实记录，并使规划需要复核；系统不会因此自动换带。

每个变更使用稳定 commandId 与规范请求摘要。同一命令重试返回同一规划的当前状态，不重复分配；同一命令修改目标或请求被拒绝。重启保留规划、预留与账本。Renderer 会话内保存未确认原请求用于重试；跨 Renderer/应用重启的通用 outbox 仍是独立 carryover，不把本次冷启动读取恢复当成 outbox 已完成。

## 界面和边界

在既有录音草稿中渐进打开分面面板，不增加概览或设备侧栏。计算、保存、选择与明确预留分开；未保存设置关闭即放弃，已保存规划和预留保留。未知兼容性可以查看和保存规划，但不能预留。设备兼容性勾选只是用户声明，不是 Output Backend Certified。

不访问未授权源目录，不读取真实 Provider/Roon，不输出正式音频、不擦除磁带、不改写原件。源私有路径仅参与 Core 内部摘要，不进入公开 IPC 或界面。照片沿用已有安全图片接口，无照片明确说明。Master/Layout 冻结、Logic Render、帧级执行资产、多介质/分段扩展、录音与归档仍由后续任务完成。
