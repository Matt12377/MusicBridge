# ADR-030：求购目标、当前持有与不可变完成度快照

状态：TASK-070 本地自动Gate通过，Owner未验收。基线 `d2735054e7f1481db9eccf058c5d400ba87b3019`。

Wanted是用户意图，不是库存状态；同一canonical可以Owned且Wanted。完成度只按确认关联与实际余额计算。Lot剩余池加Physical Copy构成在手总量，SKU历史不是持有证据；已知长度/额外长度/未知长度分开，空已知集合不构成集齐。

求购采用current row加不可变version/event，显式确认和expectedVersion防止覆盖，取消终态。旧目录修订的目标不自动迁移，动态needsReview和历史目标计数提示用户明确重绑；快照保留原id/version事实。

current只读取当前事实，即使请求旧目录也不伪称历史；capture仅当前head且绑定全批fingerprint，存储完整不可变结果。既有TASK068快照未采集新维度，保持原JSON，不能借当前Wanted/长度填旧事实。所有读取无副作用。

schema17的求购、版本、完整快照、账本在同一事务提交；容量到界拒绝而非删除历史。新增只读完整性校验接入备份full check；schema16真实合成夹具先核验后迁移，原Excel字节、人工状态和旧快照均保留。三写命令使用既有持久outbox与工作库scope。

价格使用显式货币资料代码和精确十进制字符串，不做金融计算、汇率抓取或购买动作。UI留在收藏页，保留原导航；加载、失败、未采集、未知和零持有必须明确区分。

范围和验收详见TASK-070。真实资料/设备、Owner验收、F-01、push和发布不由自动Gate替代。

快照列表的请求limit是最多25条的上限。完整分组摘要可能较大，因此列表按既有8MiB响应预算返回更小有效limit；前进按已返回条数，后退使用实际访问offset历史。此规则不改变快照内容、总数或保存容量，不删除旧记录或截断统计。
