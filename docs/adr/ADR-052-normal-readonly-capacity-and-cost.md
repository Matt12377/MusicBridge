# ADR-052 普通只读入口先验容量与完整成本

状态：采用，2026-10-03。基线RUST-014最终906a3841；Owner授权持续开发和代理承担全部测试。

普通用户开关仍固定v2-2000/4MiB。既有v3-5000/8MiB是显式可信对照，旧005 warm结果只能证明部分筛选的特定成本，不能代表当前普通入口或真实库。首先补齐实际容量拒绝后的完整Node可用性、帧开销边界和Renderer/Main/Core完整成本。

诊断为编译关闭的被动观察，原公开业务路径、单已有私有nonce控制、原Main outbox与唯一Node业务作者保持。合成大库在App启动前由Node测试工具准备，原策略写入另行经原界面/outbox证明。各进程本地clock各自计时，关联已有请求身份，不能跨clock相减。产品提交/paint与驱动轮询分开；无法拆分的阶段明确标为未独立观测。

容量失败整体拒绝而不截断。可提前检查既有本地编码预算来避免不必要spawn，但未知native退出/关闭失败继续blocked，不扩大预算或重放请求。速度不作通过阈值，按实际原值报告首启/刷新摊销与较慢场景。若数据支持固定v3准入或新热点优化，另立后续任务，不推定为Rust持久化写入授权。
