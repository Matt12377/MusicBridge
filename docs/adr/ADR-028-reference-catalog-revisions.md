# ADR-028：参考资料与目录修订分离

状态：TASK-068 本地实现；完整 V3、真实资料及 Owner 验收仍待后续。

## 决策

参考目录不进入用户库存表。ReferenceSourceVersion 记录显式输入的有界 JSON Source Pack 原 UTF-8 文本和 SHA-256；CatalogRevision 记录整理后的 canonical 项与版本映射。资料登记、目录发布和库存关联审核是三个独立确认动作，均通过 TASK-067 持久 outbox 和原工作库身份执行。

原包解析允许首 BOM，但不改变保存或摘要所用字节。用户明确选择文件或粘贴文本，预览只读；不扫描目录、不抓取网络图、不预装所谓真实书籍数据。参考图只接受合同允许的内嵌图并标明用途，不是实物照片或拥有证据。

按 bookId 保存目录链与当前指针。重复页、重复时长在相同 referenceId 和相同身份下归并；相同身份使用不同 ID、相同 ID 的元数据冲突都必须拒绝，不靠取第一条隐藏差异。发布先检查当前 revision 与包含匹配/库存事实的预览指纹，随后同事务写不可变 revision、初始 snapshot、当前指针及命令回执。

合并 N→1 可以带入多个已确认库存型号，但只贡献一个 canonical 拥有数；拆分 1→N 将原关联置为 Needs Review。没有显式映射不猜测迁移，多对多映射不支持。同一库存型号不能在同一 revision 确认到两个 canonical。候选和待审不算 Owned，也不推断 Missing；Missing 只能由用户明确声明。

## 历史与当前事实

每次发布或确认关联保存不可变完成度 snapshot。历史快照保存当时的分母、拥有/缺失/未知和库存数量，当前读取另算 currentCounts/currentEntries。后来的库存变动不能篡改旧快照。关联审核按 referenceId 整体替换；它不会写库存账本、实物编号、用户照片或既有归档。

## 持久化和恢复

collection schema 14→15 采用事务迁移，新增六张 reference 表及不可变记录触发器；中断回滚后仍可打开旧库。目录随 collection SQLite 快照保存，不使用 Main outbox 数据库。备份索引接受旧 schema 14 与新 schema 15；新版本执行只读目录完整性校验。隔离恢复只撤销外部授权及中断未完成工作，不重算或改写目录历史。默认/激活工作库的冷启接受 schema 15。

有界 JSON、分页、存储预算与失败即拒绝保护内存和历史；不因容量问题删除参考资料或已完成快照。大库完整性扫描与 2 秒 ready 策略仍由 R-020 / TASK-078 验证。

## 取舍和后续

本任务提供显式结构化资料入口与单条 canonical 编辑，不包含 OCR 或真实书籍整理。TASK-069 接非破坏 Excel 导入，TASK-070 接 Want List 和完整收藏完成度。真实资料、实际输出后端、F-01 和 Owner 接受均不由自动合成测试替代。
