# ADR-046：磁带收藏只读页面与刷新期间的条件领取

状态：RUST-009 实施范围已冻结，验证结果待形成。

RUST-008 的真实 Main 证明了活动候选空领取和原 preload outbox 行为，但页面停留主页。现有磁带墙不自动读取 current；完成度面板首次并行读取 wants，参考来源与已有历史还有其他精确请求。源码链审计确认新增八条读取在 boot 后同一已打开连接上只执行读取/解析/计算；首次 open 的迁移/恢复属于另一边界。

因此扩展八条精确 Node 辅助纯读，继续让 Rust 承担原收藏型号快照查询，并用现有 Vue 控件的真实交互证明页面读取链。保持所有作者操作和未经审定命令的保守失效，不按领域前缀放开，不迁移整个进度/目录数据库或更换页面。

refresh 先清 active，而后台真实 1,500 ms claim 可能在导出/上传期间发生。为当前 refresh 建立独有 generation/scope/version 证明与发布屏障，沿用活动候选条件领取的严格回执、完整窗口和原 Node 单次执行。失败或真写撤销自己的代次，迟到不能影响新代次；整体期限和最多一个 child 保持。

新增静态隔离 Electron collection 宿主、合成资料与独立证据 parser。实际页面动作、DOM/截图和完整 DTO/SQLite、原请求 id、child ACK/PID/自然退出同时绑定。默认 Node 和显式 Rust 100/2,000/5,000 分层；实际规模页覆盖与既有 Core 全量差分分开，不推广成真实用户性能或 Owner 验收。

代价是闭集审计与版本/完成屏障必须随领域实现复核，Node 辅助读取仍有计算成本；新增纯读不会自行恢复已经 stale 的候选。实体音乐库、导入/ZIP 暂存、编辑/捕获/登记/发布与真实服务保持原边界。生产默认、唯一数据库作者、预算、安装发布与真实验收均不改变。
