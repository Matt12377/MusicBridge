# V1 产品需求

## 1. 产品名称

Music Bridge for Roon

## 2. 首个 Provider

网易云音乐（NetEase Cloud Music）。Apple Music 仅作为未来适配器，不进入 V1。

## 3. 目标用户

已经使用 Roon、希望继续使用网易云音乐内容，并愿意在自己的 Mac 与局域网中运行本地桥接软件的用户。

## 4. 主要用例

### UC-001 首次连接 Roon

- 应用发现本机/局域网 Roon Core。
- 用户在 Roon Settings → Extensions 启用 Music Bridge。
- 用户选择一个输出 Zone。
- 应用保存 output ID，不保存未知设备凭据。

### UC-002 网易云扫码登录

- 应用生成二维码。
- 用户用网易云手机客户端扫码并确认。
- 应用轮询登录结果。
- 成功后凭据加密保存；UI 只显示用户资料。
- 过期、取消、超时都有明确状态。

### UC-003 搜索并播放

- 用户输入关键词。
- 返回分页歌曲结果。
- 点击歌曲后进入 resolving/preparing/buffering/playing。
- Roon 在所选 Zone 播放。
- UI 显示实际音质和可能的降级。

### UC-004 浏览个人音乐

- 我喜欢的音乐。
- 用户创建的歌单。
- 歌单分页加载。
- 点击整张歌单可替换队列并从指定歌曲开始。

### UC-005 错误恢复

- 未登录：跳转登录。
- 登录过期：提示重新扫码。
- Roon 未配对：打开连接说明。
- 未选 Zone：要求选择。
- Zone 丢失：停止并提示重新选择。
- 歌曲不可用：跳过或停止，不能无限重试。

## 5. 功能优先级

### Must

- Roon 配对、Zone。
- 网易云扫码登录与退出。
- 搜索歌曲。
- 我喜欢、歌单。
- 播放、停止、上一首、下一首。
- 队列。
- 实际音质展示。
- 错误与诊断。
- macOS 打包。

### Should

- 最近播放。
- 队列恢复。
- 菜单栏小控制器。
- 封面缓存。

### Could（V1.1）

- 歌词。
- 暂停/seek。
- 自动更新。
- 跨机器 Agent。
- Apple Music Provider。

### Won't（V1）

- 下载、离线。
- 解灰。
- Roon 原生曲库集成。
- iOS/Windows/Linux。

## 6. 非功能需求

- 应用空闲内存和播放内存应保持稳定；不缓存整首音频。
- 控制操作应在 200 ms 内给出本地状态反馈。
- 真实播放在合理网络下 10 秒内进入 Playing，否则显示可诊断超时。
- 所有秘密都可删除，退出账号后不可恢复。
- Renderer 崩溃不应终止已经开始的 Core 清理。
- Core 崩溃后 Main 最多自动重启一次，随后要求用户查看诊断。
