# 安全、账号与版权边界

## 允许的行为

- 使用用户自己的网易云音乐账号
- 播放该账号在当前地区、当前订阅状态下实际有权播放的内容
- 短期代理原始字节给同一用户自己的 Roon 系统
- 为播放稳定性在内存中保存临时 URL 和少量状态

## 禁止的行为

- 解灰、替代音源、跨平台自动寻找可下载源
- 绕过会员、单曲购买、地区、版权或设备限制
- 伪造账号权限、请求随机中国 IP、代理到其他来源
- 抓取、解密、去 DRM、下载或建立离线音频库
- 把试听片段伪装成完整曲目
- 将 Cookie、签名 URL 或播放令牌上传到云端日志

## Cookie 处理

POC 临时使用 `.env`：

- `.env` 已被 `.gitignore` 排除
- Cookie 不得贴到聊天、Issue、PR、截图或测试 fixture
- 日志只允许输出 `cookieConfigured: true/false`
- 正式版必须迁移到 macOS Keychain，不能长期依赖 `.env`

## 上游 URL 与 SSRF

- 只有内部 NetEase Adapter 能注册流；控制 API 不接受任意 URL
- 只允许 HTTPS 上游
- 每次重定向都必须重新验证
- 拒绝 localhost、私网、链路本地与保留地址
- 不把 Cookie 转发给 CDN，除非有明确、最小且已审计的必要性

## 音频数据

- 流式转发，不全量读入内存
- 不落盘，不建缓存目录
- 不使用 FFmpeg
- 不修改编码、采样率、位深或声道
- 停止后撤销注册，进程退出清理状态

## 供应链

网易云适配器是非官方逆向生态，风险高于正常 SDK：

- 固定版本和 lockfile
- 单独记录 `npm audit`
- 不自动跟随 latest
- 正式发布前进行依赖许可、网络行为、安装脚本和传递依赖审计
