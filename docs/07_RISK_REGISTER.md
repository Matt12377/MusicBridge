# 风险登记

| ID | 风险 | 影响 | POC 控制 | 后续处理 |
|---|---|---|---|---|
| R-001 | 网易云 API 为非官方逆向实现，接口随时变化 | 登录或 URL 获取失效 | 固定版本、解析防御、错误码 | Adapter contract tests、可替换实现 |
| R-002 | API 依赖包含解灰相关模块 | 版权与供应链风险 | 硬禁用、禁止相关接口、审计 | 正式版评估自建最小合法适配器 |
| R-003 | Roon Audio Input 文档较薄 | 当前 Roon 版本行为差异 | 基于官方示例并实机 Gate | 建立兼容矩阵与回归设备 |
| R-004 | CDN URL 有时效 | 播放前或 Range 重试失败 | 临时 resolver 刷新 URL | 依据 `expi` 精确刷新 |
| R-005 | 请求无损但账号只返回有损 | 错误标注音质 | 记录实际 level/type/br | UI 明确显示降级 |
| R-006 | Roon/上游对 HEAD 或 Range 行为不同 | 无法开始、跳播或中断 | 代理自动测试 + 实机抓取脱敏摘要 | 针对 CDN 特性补兼容 |
| R-007 | Cookie 泄漏 | 账号风险 | `.env`、日志脱敏、gitignore | macOS Keychain + 扫码登录 |
| R-008 | 多网卡/跨机器可达性 | Roon 不能访问网关 | POC 强制同机 | 下一阶段做接口选择与 ACL |
| R-009 | 传递依赖漏洞 | 本机安全风险 | lockfile、audit 记录、进程最小权限 | 定期依赖审计和替换 |
| R-010 | 服务条款不允许某些第三方使用方式 | 项目分发风险 | 仅个人本地 POC，不绕过权限 | 正式发布前做条款与法律审查 |
