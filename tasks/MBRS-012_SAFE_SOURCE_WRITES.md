# MBRS-012 · 安全标签/封面写回与活动保护

版本：1.2｜状态：NOT_STARTED｜范围：CORE。这是任务规格，不是完成报告。

## 目标

执行有限的、逐计划授权的源文件写入例外，保持旧录音只读与历史证据。

## 依赖与执行边界

硬依赖：MBRS-010、MBRS-011、MBRS-014、MBRS-005

任务依赖表示验收条件，不阻止提前编写隔离合同/mock；产品接入必须有G0记录。编号不是提交顺序。

先核对 [代码复用表](../REUSE_MAP.md)、[Rust待办映射](../RUST_TO_MBRS_MAP.md)、[模型/状态映射](../13_MODEL_AND_STATE_MAPPING.md)。文件名是当前定位线索；迁移后使用等价后继实现，不恢复旧架构。

## 实施步骤

1. 先落地有限ADR和规则矩阵，原SourceEvidence/录音读模块仍不写文件。仅受测writer/格式/字段进入allowlist。

2. 执行前复核计划Hash/授权/revision/空间与Frozen/录音/当前/暂停/预取lease；共享封面等多资源按稳定顺序取锁，不强停音频。

3. 备份、journal、临时替换、数据库提交分别设计崩溃恢复；备份/staging不扫入音乐库，未验备份不自动删。

4. 仅改选中字段、保留多值与未知标签及音频payload，独立回读验证；整文件Hash可因标签改变而改变，不能更新历史绑定来掩盖。

5. 逻辑AssetID保留、revision递增；旧lease不能取新版。Frozen默认拒绝原地修改，版本化例外需要保全旧字节和独立确认，不是改个revision就放行。

6. 撤销前核外部后续变化，冲突即停止；旧native关系可标STALE但不挡新直送。

## 验收

- [ ] **MBRS-AT-012-01 / integration / 1.1**：每个允许writer/格式目标字段正确，音频与非目标元数据不变，备份可读可验证。

- [ ] **MBRS-AT-012-02 / fault / 1.1**：替换/DB提交各阶段故障有journal恢复，无隐瞒半写。

- [ ] **MBRS-AT-012-03 / unit / 1.1**：过期计划/源变/未授权/冻结/不支持格式被拒绝。

- [ ] **MBRS-AT-012-04 / integration / 1.1**：活跃/暂停/预取/录音lease时写入延期或安全阻止，不打断原样读取。

- [ ] **MBRS-AT-012-05 / integration / 1.1**：写后原ID保留，新lease取新revision；旧URL不可返回新内容。

- [ ] **MBRS-AT-012-06 / integration / 1.1**：撤销前后外部变更产生冲突，不恢复旧备份覆盖新修改。

- [ ] **MBRS-AT-012-07 / ui / 1.1**：MB-only/目录封面/音频内嵌/标签写回范围清楚，原生Roon待刷新不阻断本地直送。

- [ ] **MBRS-AT-012-08 / integration / 1.2**：有效规则仅授予受控Organizer具体计划写权限；原录音读模块仍不可写，Frozen默认拒绝修改。

- [ ] **MBRS-AT-012-09 / security / 1.2**：plan_hash、scope、操作集合和授权引用由服务端验证；Schema正确或客户端approval字段不能授权写文件。

## 禁止

禁止为新功能弱化旧录音校验、直接改冻结Hash或静默转码。

## 阻断处理
