# TASK-055：分面规划、现有库存推荐与明确预留

## 身份与授权

Owner 已持续授权完整 V3 开发。基线 `79ca787240226eefb87cba49c7f92c35232be45a`，分支 `codex/task-055-v3-layout-media-select`。只使用隔离库存、草稿和音频夹具验证；不访问真实 Roon/源目录或操作实体录音设备。

## 范围

1. 选曲后立即可进入分面与库存推荐，不要求先完成源验证或 Logic。优先用有效实际源时长；未绑定时使用明确标记的 Roon 草稿估算；未知时长不伪造。已绑定但内容变化/不可用时明确阻断最终适配，不能静默回退冒充源已验证。
2. Cassette A/B 分别计算容量，支持手动分界和保持全局曲序的辅助平衡。按每面实际相邻边界计算 Compilation 默认 5 秒；Concert/Continuous 默认不添加间隔。Lead-in、Tail、曲间覆盖和 Keep With Next 分开表达，空面不自动添加静音。不得以总时长通过替代逐面通过，不改变草稿全局曲序。
3. DAT 单连续 Program 按独立容量计算，不伪造 A/B、自动 Track ID 或已认证设备兼容。当前规划采用明确毫秒时基，不能冒充最终执行帧时间线。
4. 推荐仅来自已有且确认可用的空白/已擦除库存，涵盖 Pool 与已实例化 Copy；排除已录音、预留、不可用、未知和受保护库存。最低未拆保留量按型号整体计算，默认优先已拆空白。照片与型号/版次/时长、可用数量、约束原因明确显示。容量或设备兼容尚未确认标记待确认，不允许宣称正式可录。
5. 用户明确选择和预留时，在单一事务中分配/关联实体 Copy、减少相应 Pool、写库存/规划账本。禁止重复预留、跨草稿占用、负库存或复用旧命令更换目标。取消预留保留永久实体身份并恢复原空白/已擦除状态，不自动返池或增加拥有总数。库存页不能绕过录音预留归属。
6. 保存规划与输入快照，草稿曲序、间隔、源规格或库存约束变化后重新计算并显示需要确认；已选磁带不会自动更换。预留是准备动作，不代表 Source Lock、Master/Layout Freeze 或正式录音。
7. 库存不足、边界不可行、兼容性未知、收藏保护命中、事务冲突和回执未知均有可恢复界面。取消浏览不写入、不影响播放。使用现有录音页面渐进展开，不添加概览/设备侧栏入口。
