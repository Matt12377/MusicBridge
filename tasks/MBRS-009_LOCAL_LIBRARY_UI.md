## 实施步骤

1. 复用侧栏、design tokens、玻璃背景、播放条和virtualWindow；只增本地索引数据与流程，不整体重设计。

2. 首用无库、扫描中部分可用、暂停/取消、权限/坏文件、根离线、Roon断开和格式不支持均准确显示；详情不等全库/联网封面。

3. 读取006/007实际播放器状态，单一本地入口只选Roon Zone；本地播放不弹必须先匹配提示。

4. 原始与覆盖、发行/格式/音频参数分层展示，unknown不填假值；重新定位保留收藏，预览源写范围明确。

5. 10万虚拟列表与分页、滚动返回/焦点/键盘操作实际检查。未完成播放时明确未就绪；任务可开发但整体验收等待006/007。
