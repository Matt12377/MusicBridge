## 范围

扩展现有 diagnostics，贯通 Renderer/Main/Core 的受控身份和本地单调时钟，记录排队、上游调用、页面、SQL、事件估计负载和事件循环。不能跨进程直接相减 performance.now；估计 JSON 字节数不能写成 Electron 实际线上字节。

本任务不改变播放、分页、库存、录音准入或授权行为。诊断失败不能改变业务结果；关闭时不为每个 tick 序列化全队列。不能记录账号、曲目/Zone 身份、私人路径、URL、凭据或任意 payload。

## Gate

1. Trace 开关、固定容量、脱敏、单调时钟、错误隔离与资源 dispose 行为测试。
2. 正式 IPC/运行时接线测试，确认关联及关停不泄漏。
3. 可控基线复现播放前剩余分页、详情先完整收集、进度事件包含完整队列；保留 50/500/5000 合成负载结果。
4. 合同/Core/Renderer 类型、相关回归、生产构建、control-plane、boundaries 和 diff-check；全量基线日志保留原始结果，不缩小测试范围或新增跳过。
5. 开发构建、实际 Mac/Roon 与设备指标分别标注执行状态；未具备真实测量条件不得填通过。
