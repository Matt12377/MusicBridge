# MBR-003 — 快速切歌与 Roon 读取取消修复

基线：`e2eac26eecb835224f2a00477552e1f0f727c5fb`；分支：`codex/fix-playback-roon-runtime`。

Owner 于 2026-10-02 报告网易云歌单快速切歌个别歌曲无法播放、Roon 浏览结果不可用。范围是复现并修复这两条路径的确定缺陷，继续 Electron / Vue / Node / TypeScript；保留用户资料与既有功能，不扩展为语言迁移或发布验收。

- 歌单集合首播在途时接受后续点击，旧分页、回执与错误不得覆盖新选择。
- 尚未派发的旧队列替换取消；已经派发的播放仍执行真实停止与清理。Stop 未确认时不能开始新播放，Stop / Zone 保护及连续 Next 语义保留。

- 当前 Roon 读取取消时显示可重试错误；离页和过期请求保持静默，已有数据刷新失败时保留内容。
- 播放取消映射为公开 CANCELLED；真正播放失败留下有界错误码诊断，不公开 URL、凭据、用户资料或私有错误栈。
