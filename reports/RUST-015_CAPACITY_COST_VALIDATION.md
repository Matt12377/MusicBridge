## 退出修复及保留失败

Source14 在 5,000 fresh 缺唯一 node.exit 而整体失败；十轮 Main 自然 0 不能替代完整 Core 关闭证据。Electron 官方 43.4.0 UtilityProcess 的 exit.finally 清除原 stdout 监听；真实 PassThrough 受控 RED 复现 exit→监听清除→晚到原关闭帧。旧现场没有独立 fd1 错误旁证，不能认定唯一根因。

Source15 只在既有 Main probe/观察测试及原 index 接线三文件增加诊断尾部收口：exit 同步 pause，microtask 只恢复本观察器三个监听并 resume；真正 end/close 才完成，幂等且不填造事件。原业务 Core shutdown 和 outbox close 结束后，诊断包缓存单 flight 排空 Main stdout 和原 Core stream，整体最多 5 秒；失败发原 probeFailed 并由 Gate 拒绝。默认诊断关闭包不新增等待，业务关闭 ACK/预算不变。

01–14 的失败、有效 RED/GREEN、Source12 的 180 秒测试进程失败、Source13 的旧 VM binding 软件失败及旧普通窗口失败/校准均保留。2001-15 在输入草稿 2 但尚未 Save 时被会话中断，runner/Main 消失且无完整运行收据，明确不接受；同一 Source15 签包以全新 2001-16 完整重做通过。没有覆盖原件或补写成功。
