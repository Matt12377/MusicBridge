## 已确认的事实

1. 原数字 IPv4 媒体地址的实际播放曾在精确 socket peer 准入前被拒绝。配对 Core 的固定图标直连请求可返回 200；同一 Core 的系统代理感知请求曾返回 404。不能以信任代理或转发头解决。
2. 仅改为系统 `.local` 主机名后，真实 Roon URL 已使用该主机名，但仍在 Gateway 收到音频请求前超时。不能据此声称修好。
3. 系统主机名同时存在 IPv4 与 IPv6 link-local 解析，而媒体监听是精确 IPv4。为排除这一变量，试验了 OS DNS-SD 注册、只含本次绑定 IPv4 的临时别名，并验证发布撤销、超时、失效及 actor 生命周期。
4. IPv4 专用别名的实际 Roon 请求仍超时。Roon 日志中的地址、端口和受限媒体路由确实对应当前 listener，不是旧端口。**IPv6 因而不能视为已证明的根因，IPv4 别名也不是已验证修复。**
5. 从配对 Core 对当前 listener 的数字地址和 IPv4 专用别名做固定图标直连，均得到 HTTP 200、PNG 内容和正图标字节。别名解析仅返回精确绑定 IPv4。这只能证明该探测进程可连通，不能证明 Roon 的实际 HTTP 客户端已可取流。
6. Core 的原生系统代理分类包含 PAC；数字地址与 `.local` 地址的静态回退分类不同。受限的原生 PAC 求值返回错误，未取得可证明的实际 Roon PAC 决策。不得把当前不确定性写成“已确定 PAC/IPv6 根因”。
7. 系统短主机名在 Core 无可用解析；精确本机网卡的标准 HTTP 端口绑定返回权限拒绝。该端口试验未申请提权，未改端口权限或网络配置；后续获准代理例外的认证尝试见前节。

## 19:44–19:50 按实际连接链路复现的新增结论

**已证明存在 Core → 本机 HTTP 代理 → Gateway 的失败链路；真实播放仍未修复。**

本轮先核对进程，发现 Owner 当前已打开安装版，控制端口属于安装版 Core，而非刚启动的开发窗口。已正常退出没有自有 Core 的开发窗口，保留 Owner 的安装版不动；后续对照全部绑定到同一安装版 Core 和精确媒体 listener，且检查对照结束时 listener 未改变。没有混用实例作为新源码验收。

从配对 Core 使用其当前配置的精确 HTTP 代理，做四组自有固定图标对照（不是音频验收）：

| 地址 | 直连 | 经当前配置的 HTTP 代理 |
| --- | --- | --- |
| 当前 listener 的数字 IPv4 | HTTP 200 / PNG | HTTP 404 / 无图标字节 |
| 系统 `.local` 主机名 | HTTP 200 / PNG | HTTP 502 / 无图标字节 |

又用受限 keep-alive 探测保留连接、通过只读 socket 元数据关联两端：

- 直连：Gateway 实际接收 socket 的 peer 是配对 Core，HTTP 200；代理进程没有对应 Gateway 出站连接。
- 经代理：Gateway 实际接收 socket 的 peer 变为 Gateway 本机，HTTP 404；已观察到代理进程到该 Gateway 的对应出站连接。
- 因而代理的 `DIRECT` 规则只表示**代理自己直连目标**，不表示 Roon 客户端绕过代理。不能拿该规则标记当作端到端直连证据。

不只依赖图标探测：已对齐安装版当前 listener 的历史真实 Roon 在线音频 URL（受限 `/stream/` 路由）、同时间代理连接记录以及 Roon HTTP 404。该音频请求确实经过代理；URL、票据和用户曲目均未导出。较早开发版 `.local` 本地音频 URL 的真实 Roon 502 与代理端 DNS 失败记录也吻合。旧音频重试记录只读观察，没有重签或重放。

**当前已定位的失败点：中间代理改变了 Gateway 看到的 socket peer，精确配对准入按设计拒绝；主机名方案另在代理 DNS 跳失败。** 这能解释 Gateway 无音频业务请求、零音频字节及 Roon 媒体错误。此次实际媒体 URL 使用 HTTP，不是媒体 TLS 握手失败的证据；Mousa 的 HTTPS Core 控制连接是否经过代理仍需单独核对，不能从媒体链路替它下结论。

修复目标应是让 Roon 到精确媒体地址**真正直连**，而不是信任代理头或放宽 peer。Core 代理例外或应用级代理选择是否有效，须用 Roon 自身连接再验证；不能只改一个设置后声称成功。本轮没有改代理、网络、设备、音量，也没有发起新的播放控制。

原始诊断、UI 收据、屏幕截图、用户曲目、主机名、地址与临时脚本仅在私有证据目录，不进入 Git。
