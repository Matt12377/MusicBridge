## 根因与修复

1. 原资料合同硬限制 500 条，完整目录被当作格式错误拒绝。统一上限改为 2,000 条，1 MiB 字节限制和身份去重规则不变；界面从合同常量显示上限，超限明确说明，不截断。
2. Excel 原只接受 ISO 日期和裸 IEC 罗马数字。兼容明确的年月日点号、斜线、横线格式和 TYPE 前缀；校验真实日期，拒绝混合分隔符及非法日历值。
3. 多时长单元格保留原文，规范值为未知时长并提示元数据待确认；不推断每种时长数量。数量和已用公式仍须缓存存在并明确确认，不执行公式。
4. 旧 TYPE 标签的历史规范值可能是 unknown。只读校验允许精确匹配旧规范快照，不回写旧库存或旧修订。
