node --test scripts/ci/test/verify-v3-acceptance.test.mjs

使用项目固定 Node 22.23.2。默认命令允许 mapped + pending，输出的是 `V3_ACCEPTANCE_INDEX=PASS`，不是 V3 产品 PASS。`--require-fresh` 要求每个 mapped 条目的全部映射测试有新鲜通过证据；unmapped 与 gaps 仍输出/保留，不能被该选项暗清。

每条 `freshGate` 可在全部 `mappings` 有精确通过 case、日志明确成功行、exit0 和一致候选后设 `{state:"passed",evidenceIds:[...]}`。这也仅通过列明的软件子范围，不消除 gaps 或 externalRequirements。失败可记录为 failed；pending 不绑定假证据。不同 evidenceKind 分开记录，即使复用同一次完整日志。

校验器拒绝遗漏/重复/未知 ID、来源文本/hash漂移、路径逃逸/符号链接、不存在的测试声明、动态未展开名字、日志只有总通过数或 SKIP/TODO、失败却声称通过、候选漂移、控制数据循环及外部门冒 PASS。同名跨文件 case 不能重复使用一条无文件区分的日志成功行。它是有限证据一致性检查，不是签名平台，不能独立证明人工填写的收据真实执行；root 仍需读取完整新日志并审核逐条 covers。
