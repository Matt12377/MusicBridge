# Mousa 4.1：日常开发构建提速

开发入口根据改动范围复用界面、桌面端和共享核心构建层；媒体 Worker 增加保留优化的开发档位。用户原有 `dev:desktop` 命令不变，正式安装包继续要求 Release。

- 基线：`5b07fcba5a0ef5aeeea0fda0f86ecd67f29fabd1`。
- 实现：`0df91b59ce9c23749edbadd3b57aa62e7e5ce124`。
- 隔离实现分支：`codex/mousa-4-1-dev-build-speed`。
- 整合分支：`codex/mousa-4-1-artists-search`，工作目录 `worktree/v4`。
- 报告身份为本文件的 Git 提交；下一任务从本报告最终 HEAD 创建分支。远端身份以推送后读回为准。

## 改动与适用范围

1. 无变化时复用完整产物；仅界面变化只构建 Renderer；主进程、预加载等桌面源码变化只重打包桌面端，复用 Core 和原生程序。共享核心、依赖、配置、原生输入、相关构建环境变化或产物缺失时执行完整构建。
2. 新增 Cargo `development` 档位，继承 Release 优化，关闭 LTO、使用 16 个编译单元并启用增量编译。仅开发 Core 入口显式选用它，默认原生构建仍使用原 Release。
3. 清单记录构建档位；旧清单缺省按历史 Release 兼容，未知档位拒绝。正式安装包的现有捕获入口默认拒绝开发档位，原二进制摘要与工作树归属校验保留。
4. 开发缓存版本更新，升级后先执行一次完整构建；新增桌面端复用层。失败构建撤销完成声明，相关 Rust 环境变化也使缓存失效。

## 本机实测

Node 22.23.2、pnpm 10.17.1、macOS arm64；构建前确认 LifeWeave 为真实外置挂载且可写。所有编译副本、缓存、测试临时文件和日志都位于外置构建根。

以下是完整命令的单次耗时，包含同步、构建与 `electron --version` 检查，不包含应用启动。依赖与 Cargo registry 已有缓存；不是 P95，也不是严格冷机对照。

| 场景 | 耗时 | 结果 |
| --- | ---: | --- |
| 无源码变化，复用产物 | 2.013 秒 | 退出 0 |
| 仅 Renderer 源码变化 | 5.109 秒 | 退出 0，仅构建 Renderer |
| 仅主进程源码变化 | 8.660 秒 | 退出 0，仅重打包桌面端 |
| 测试源码恢复后重打包 | 7.550 秒 | 退出 0，原字节已恢复 |
| 原 `worktree/v4` 整合后的首次完整开发构建 | 27.224 秒 | 退出 0，开发档位首次编译 |

增量测量在隔离树中使用临时源码注释触发变化，测试后恢复原字节；各次 Native 和 Core 产物摘要保持。新隔离编译副本首次准备依赖并完整构建耗时 35.291 秒，不能将其当作已有依赖环境的日常增量时间。

同一隔离源码树、已有 registry 缓存、各自原生目标档位首次使用时，原 Release 编译为 24.291 秒，development 编译为 8.927 秒。旧入口在 Release 目标已缓存时强制完整构建为 16.930 秒，与上述首次开发档位构建条件不同，不作整体加速比例结论。

整合后在 `worktree/v4` 执行原命令：

```bash
corepack pnpm@10.17.1 dev:desktop --build-only
```

退出 0，日志确认完整构建路径、开发档位清单、沙盒 Preload 依赖门禁通过及 Electron 43.4.0 可执行。构建内部计时为 25.47 秒，完整命令为 27.224 秒。原入口继续要求 Node 22；`--rebuild` 强制完整构建，日常测试无需加此参数。

## 回归与交付边界

- 新增桌面端复用、开发档位正式包拦截、未知档位拒绝的行为回归：修复前退出 1。
- 构建副本、分层复用、存储边界、输出发布及档位资格：16 项通过，0 失败、0 跳过，退出 0。
- 实际 development Worker 的桌面路径定位、合成音频元数据读取、打包路径和摘要拒绝：3 项通过，0 失败、0 跳过，退出 0。
- Rust development 档位已有的 5 项单元测试通过，退出 0；实际 Worker 发出 Ready 协议后可自然退出。
- 实际 development 二进制可用于开发捕获，默认正式包捕获拒绝；无 `--profile` 的实际构建仍产生 Release，默认正式包捕获通过。
- 临时测试改动已恢复；快进整合保留原用户工作区和独立 `v4-ui`。

本轮只验证构建、构建资格与定向 Worker 行为，没有生成新 Mac 安装包、启动 Mousa、操作手机或访问真实曲库。未测量关闭 LTO 对真实曲库运行时性能的影响，未将构建通过写成应用、设备或 Owner 验收。首次构建、共享输入变化、环境变化仍可能需要完整编译；本轮没有扩大到应用冷启动或数据库索引优化。

私有原始证据位于外置临时目录 `mousa41-dev-build-speed-wsphcg19`，包含基线、回归红绿结果、原生档位检查、五次分层构建测量以及整合后原命令的完整日志。日志与二进制不进入 Git。
