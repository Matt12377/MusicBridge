# 磁带书籍参考图收尾

## 身份与范围

- 分支：`codex/cassette-reference-images`。
- 基线：`812e6a07bb424da19a857812ce02d1e585597dc4`。
- 实现：`3d0aac9007eb3ec89d9dd2762bb66ab27f841f14`；报告身份由本文件所在提交确定，下一分支从本分支最终报告 HEAD 创建。
- 本轮只修复参考图导入与展示，不更改库存、实物照片、所有权关联、Roon 播放逻辑或容量执行权限。

## 根因与实现

此前导入的是无图片的结构化目录，收藏墙仅读取实物代表照；文字目录登记并不等于扫描图片已导入。带图修订还受原始文字包 1 MiB 和普通命令信封 2 MiB 的预算限制。

1. 参考图修订独立限额为 4 MiB，只有对应发布命令允许必要的信封开销。原始 Source Pack 仍限 1 MiB，其他命令原限额不变。
2. 增加严格 UTF-8 JSON 文件修订入口，经既有校验、基线预览、独立确认、Main outbox 和不可变目录发布流程保存。
3. 重新整理已有来源时加载当前发布修订，避免回退到原始无图条目。
4. 收藏墙实物照片优先；没有实物照片时展示同品牌、同型号、兼容类型的书籍参考候选。明确年份/版次有冲突时不补图，不自动确认关联。
5. 型号详情展示多个候选版次及来源页。图片采用保留比例、预留尺寸、延迟加载、替代文字与读取失败反馈，不改变现有页面结构。

## 授权本地导入与界面核验

- 从用户提供的扫描书提取参考图，保留型号、年份及来源页证据；多型号混排和无法确认的裁片剔除，不生成或猜测图片。
- 在开发版实际界面选择修订文件，核对新增/移除/合并/拆分均为零，独立确认后收到“目录修订已发布”回执。
- 只读数据库检查：新旧目录除图片字段外一致；原始来源逐字节相同；八张库存/实物/照片相关表的逐行摘要一致；quick_check 与 foreign_key_check 通过。导入前一致备份保留在本地。
- 已观察收藏墙出现书籍参考图，型号详情并列显示不同年份图片；实物照片仍单独计数，参考图不作为持有或版次确认事实。
- 旧的小窗口一度未及时刷新画面；通过窗口缩放刷新后核对成功回执及实际展示。未绕过应用直接写数据库，也未因陈旧画面重复发布。
- 用户扫描文件、图片、个人库存内容、源文件路径、数据库及导入回执不进入 Git。公开测试仅用合成资料。

## 保留项与交付边界

本轮完成参考图功能及已核验首批导入，不声称每个库存条目都有准确图片。无法可靠配图的条目保留占位；同型号不同版次显示为候选，具体实物版次和图片正确性仍需 Owner 验收。真实照片优先分支有自动检查，本地没有实物照片样本，因此不声称完成真实混合照片验收。

应用由当前分支生产构建启动，供人工查看。Git push、Owner 验收、真实播放听感、正式容量、签名公证、merge 和发布分开记录；本轮不进行 merge 或 release。
